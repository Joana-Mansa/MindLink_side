# 🌿 MindLink mental-health application

The fuller application snapshot: HTML/JSP screens, JavaScript, servlet configuration, compiled classes, bundled libraries, a WAR and a MySQL Workbench model.

## 🚀 Explore locally

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/index.html`. This previews the static screens. Authentication, saved assessments, appointments and JSP rendering require a backend and are not functional in the static preview.
